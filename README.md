# Agent Office — หน้าเว็บ

หน้าเว็บของ [IT Agent Ops Floor](https://mrgalaxy6544.github.io/agent-office-web/) สำหรับคุยกับ VISION และสั่งงานทีม AI Agent

repo นี้มีแค่หน้าเว็บ ไม่มีข้อมูลหรือ token ใดๆ งาน แชท และโค้ด worker อยู่ใน repo **private** `agent-office`
หน้าเว็บเชื่อมต่อกับ repo นั้นด้วย token ที่ผู้ใช้ใส่เอง และ token นั้นเก็บไว้ในเบราว์เซอร์ของแต่ละเครื่องเท่านั้น

อัปเดตหน้าเว็บ: คัดลอก `docs/index.html` จาก repo `agent-office` มาทับไฟล์ `index.html` ที่นี่
